What is this?

This is a letter submission page! Write your letter in the text area box, add a title and a description if you want, and click send!

Where does it go?

When you send a letter its delivered to an online public archive where it becomes part of an ongoing collection of correspondence. Anyone who visits that archive may be able to read what you have written. So please be careful including sensitive and/or personal information in your letters.

Instead of a sealed letter being sent to a single person, it'd be more accurate to think of it as pinning a letter to a community-center board.

How was this made?

The post office was built in connection to Are.na (an online social platform for collecting and organizing ideas) - so when you submit a letter, instead of it being stored on this website, its delivered and stored on my Are.na page.

This connection from the post office to Are.na is established through the use of Are.na's API!

What is an API???

If you're wondering what an API is, so am I! Even though I've successfully built this page using an API, I'm still largely unsure of what an API actually is... The concept is still super vague to me but I'm going to do my best to define it within the context of how it's being used here specifically.

API stands for Application Programming Interface. It's technically a "bridge", used by 2 different pieces of software to communicate with each other. If this website is a house and Are.na is another house - then Are.na has kindly provided a "bridge" (API) that allows information to be passed between our 2 homes! The API is the thing that establishes the connection between the 2 houses/softwares.
