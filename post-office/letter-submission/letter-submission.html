What is this?

As an angsty teen in the early 2010s, I used Tumblr WAY too much(...if you don't know what that is... CONGRATULATIONS!). Tumblr let people send anonymous messages. And replies to messages could be sent privately or posted publicly. I loved this "system"!!! So this post office is my personal take on that sort of thing.

Where did it go?

Letters are automatically posted here on my are.na page!

How was this made?

This post office is connected to Are.na - which is basically a social media platform for adults that used Tumblr as teenagers
When you submit a letter, its delivered and stored here, on are.na.

Created using Are.na's API

What is an API???

If you're wondering what an API is, so am I! It's all still super vague to me

I can't really explain what it is but I can explain what it allows me to do!
Without the API this page would look the same. You'd still be able to type a letter and click the "submit" button, but nothing would actually be submitted. Saving the contents of letters in this way essentially requires modifying this website's code. And browsers (i.e., Chrome, Firefox, Safari, etc.) need special permissions to modify files/code on any website.
So the API is basically a contract that tells the browser what it should and shouldn't do when you send a letter!
