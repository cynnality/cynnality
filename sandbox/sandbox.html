about this website

a personal project i started to learn basic coding/web dev stuff/hosting sites. inspired by indieweb, slow web, & digital garden concepts.

the only rule im following while building this site is everything must be free. the domain name is the only thing i've spent money on ($8 / year w cloudflare).

design programs

  • i use inkscape to create/edit icons/svg's/vector graphics (a 100% free alternative to adobe illustrator)
  • i use gimp to create/edit graphics/raster imgs (a 100% free alternative to adobe photoshop)

developing/hosting

  • i use visual studio code to develop and update this site. i'd been working on this for months before i started using vscode & thats when i really started understanding how to code and implement things as i envisioned them. i think there are paid versions but i've only used the free version and its been SO helpful
  • i use github/github pages to get all of this on the internet. this step of the process (creating a repo, connecting it to github pages) was by far the most difficult part for me. i almost gave up 50 times at this step. i don't even remember how i did it. i only use the free versions but there are paid versions of github and github pages
  • i bought the domain name through cloudflare. i could've kept this project 100% free by using the subdomain that github pages provides but i underestimated how bothered i'd be by not having my own domain. cloudflare was one of the only platforms i found that promised not to price jump after the first year
  • i genuinely could not have created this without browser developer tools and im being so serious
