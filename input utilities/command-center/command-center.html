Before you explore

I use this page as a kind of data checker and dashboard for my basketball database. It's one of the most useful tools I've built for this project so far, and I plan on continuing to expand it over time.

This website runs locally on my laptop, where I use a custom local server that lets me write directly to my data files. Because of that, unless you're somehow using my laptop on my local network, you can't actually edit or overwrite anything here.

So feel free to browse, click around, and explore! I keep this page online both for my own convenience and for anyone who happens to come across it. For you it might be a behind-the-scenes look at the kind of information I'm collecting, and maybe you'll even learn something new about basketball.
